Why · 背景
AI 是平台最大的增量成本，
也是下一笔增量收入
模型调用费用随 Agent 规模线性增长；如果只算成本不算收入，AI 功能每多一个用户，平台就多亏一份钱。定价必须回答三个问题：
谁在用？
平台管理员 · MSP · 直客
三级用户 × SaaS/私有化 两种部署
付什么？
授权费（License）与用量费（credits / token）
必须分层，不能混在一口价里
怎么计量？
平台模型池按调用扣 credits
自带模型（BYOK）按 token 消耗量显示

Core · 三层定价模型
每一层，回答一个「谁付钱、收什么」
① 授权层AI 功能 License
AI 功能 = Agent，License 逐项控制开关
所有用户、所有部署都必须购买。按 Agent 数 × 期限计费（功能费用），复用现有授权体系（产品线 × 功能模块 × 数量 × 有效期）。
平台统一收按 Agent 数 × 期限14 个内置 Agent（告警降噪 · 根因分析 · 工单起草 · Copilot …）
② 用量层平台模型池 · credits
订阅平台模型，按调用扣 credits
仅 SaaS 可订阅。谁调扣谁的：租户扣租户、MSP 自用扣自用份额。平台定价，加购走预购包。
¥0.10 / credit年池 ≥100 万 −25%谁调扣谁的AI-CRED 预购包
③ 自带层BYOK · token
自带模型（云端 Key / 本地部署），不收模型费
SaaS 与私有化统一。按 token 消耗量显示；AI 功能仍由 License 控制。MSP 的池 = 自营定价转售（厂商不抽成），直客的池 = 自用。
token 消耗量显示不收模型费License 控制功能MSP 自营定价

Matrix · 谁看到什么
五个管理视图，一套计费后台
AI 计费中心按「管理员角色」分视图，第一维度是角色、部署是角色的变体（OP = 私有化）——每个角色只看到自己职责范围内的数据。
SystemAdmin
平台管理员 · 全平台
  • 模型池总池与分配
  • 平台收入（License + credits + 软件费）
  • 全量价目表 · 全部租户
  • AI 功能 License 汇总
MSP Admin SaaS
SaaS · 转售/自营
  • 批发 credits 池（转售 + 自用份额）
  • 名下租户转售方案 · 毛利
  • BYOK 自营 token 入口
MSP Admin OP
私有化 · 自营
  • 无平台 credits（不能订阅平台）
  • 自营 token 池 · 租户订阅管理
  • MSP 定价 × token = 订阅利润
  • License 状态（平台手里）
UserAdmin SaaS
直客租户 · SaaS
  • 自己的 credits 用量 / 池 / 账单
  • 或 BYOK token 用量
  • AI 功能 License 状态
UserAdmin OP
私有化直客
  • 仅 BYOK（本地 / 云端 Key）
  • 只看到自己租户的数据
  • 无 credits · License 状态

05 / 10
Revenue · 平台收入
两种部署，两套收入，License 贯穿始终
SAAS 部署
License + credits 销售
平台池订阅按调用扣 credits，随用量增长线性放大——AI 用得越多，平台收入越高。
  • AI 功能 License（14 Agent 逐项 · Agent 数 × 期限）
  • 平台池 credits（¥0.10 / credit · 批发档 −25%）
  • AI-CRED 预购包（50K / 200K / 1M）
  • MSP 转售差价由 MSP 赚（平台收批发价）
私有化部署
License + 平台软件费
私有化无法订阅平台池，收入结构更稳——License 是订阅式收入，软件费按部署节点收。
  • AI 功能 License（订阅式 · 可续费）
  • 平台软件费 ¥50,000 / 部署节点 / 年
  • MSP 自营订阅利润归 MSP（厂商不抽成）
  • 厂商退出模型调用成本风险（本地/自带 Key）
06 / 10
MSP · 渠道角色
MSP 是「二级平台管理员」，赚两份钱
SaaS 转售
批发池按平台价拿，转售给名下租户赚差价。池 = 转售配额 + 自用份额（自用调用同样扣 credits）。
私有化自营
租户订阅 MSP 的模型服务，MSP 按 token 自定价格 —— 订阅利润是私有化商业模式的重要一环。
边界清晰
MSP 不能直接开通产品，只能给名下租户开通；自己用产品需开通自有租户。License 始终在平台手里。
· MSP 用系统内定价配置 + 订阅账单管理自营订阅（已产品化） · 厂商不抽成 → MSP 有动力把模型服务卖给更多租户
