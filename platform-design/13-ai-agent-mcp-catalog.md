### 3.1 MCP 端点与调用管理（2026-09-01 补充 · 原型已落地）

**端点生命周期**（`prototype/ai/ai-platform.html` MCP Tab）：
- **生成端点**：表单（暴露 MCP / 工具范围 / 权限与数据范围 / 调用限制）→ 生成即入列表 → 弹窗展示**端点 URL + Token（仅展示一次 · 可复制 / 复制完整接入配置）**→ 确定关闭
- **轮换凭证**：确认 → 新 Token 展示（仅展示一次 · 可复制）→ 旧 Token 立即失效 · 轮换记录审计
- **吊销端点**：确认 → 外部 Agent 立即无法访问

**调用限制（管理员配置 · 组织级共享配额）**：
- 维度：默认频率（次/分钟）· 每日次数上限 · 并发上限 · 超出策略（限流排队 / 拒绝 429+告警）
- **作用域 = 组织级共享配额**：管理员在「生成对外端点」时设置，**对组织内所有使用该端点的成员生效**（成员共用配额，不单独开启）；成员级覆盖为后续版本
- 端点表展示每个端点的调用限制列 · 触发限制与用量突增记审计并通知管理员

**自定义 MCP 口径（2026-09-03 拍板 · 修订 2026-09-01 口径）**：
- MCP 由平台统一提供（产品 6）· 各 Agent 的 MCP 授权在 Agent 编辑面配置（最小权限）
- **自定义 MCP 仅 MSP / 私有化开放**（注册走审批 + 安全声明：端点托管方/数据出域边界）· **SaaS 直客关闭**（注册入口对直客隐藏）
- 外部接入走「生成对外端点」；多模态能力经模型接入层调用（见 §三 移出注）
